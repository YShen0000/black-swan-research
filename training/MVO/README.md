# Standard MVO Training
This is the **first** part of the training process.
## Objective
1. Get familiar with the project
2. Understand the code (input, output, functionality of each sections in the code)
3. Learn how to present results
## Procedure
1. Carefully read the documentation of MVO
2. Dive deep into the code and make sure you understand every code block (not necessarily every line)
3. Run the code to obtain portfolio for Swan9 with betas from Swan4 to Swan8
4. Record your results (weights.csv, injected_results.csv, tradeinfo.csv)
5. Organize your results into a Type E graph and present
